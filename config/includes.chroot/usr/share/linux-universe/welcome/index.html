Добро пожаловать в Linux-Universe

Полноценная операционная система на базе Ubuntu 26.04 LTS — лёгкая, приватная и созданная для всех: от новичков до разработчиков и творцов.

🛡️

Приватность по умолчанию

  • Зашифрованный DNS (DoH/DoT) — без слежки за твоими запросами
  • Блокировка рекламы и трекеров на уровне всей системы
  • Режим Air-Gap — мгновенное отключение всех сетей одной кнопкой
  • Автоочистка кешей браузера при выходе
💻

Dev-Box Workspace

Сейчас система спросит, на каких языках ты программируешь, и сама подготовит изолированные окружения — без ручной настройки.

🎨

Creator Studio

  • Shotcut — видеомонтаж
  • GIMP и Krita — обработка изображений и рисование
  • Inkscape — векторная графика
  • Audacity — работа со звуком
🔗

Совместимость

  • Wine — запуск Windows-приложений
  • Waydroid — запуск Android-приложений
  • Docker — изолированные контейнеры для сложных задач
🤖

Локальный ИИ-помощник

Полностью офлайн, без отправки данных куда-либо. Запускается из меню приложений в любой момент.

🔒

Безопасность

  • Антивирус-сканер (ClamAV) — проверка по запросу
  • Firewall (UFW) — включён по умолчанию
  • Timeshift — снимки системы с быстрым откатом
  • KeePassXC — офлайн-менеджер паролей
📚

Библиотека

Встроенная коллекция книг на русском языке из общественного достояния, читалка Readest и плеер аудиокниг Cozy — уже готовы к использованию.

🚀

Готово к запуску
